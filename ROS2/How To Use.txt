1. 워크스페이스의 src 폴더로 이동

cd ~/[워크스페이스 이름]/src 

2. ament_cmake 빌드 타입을 사용하여 C++ 패키지 생성
ros2 pkg create --build-type ament_cmake [원하는 패키지 이름]

3. 워크스페이스 루트로 이동

cd ~/ros2_ws

4. 특정 패키지만 빌드(무조건 워크스페이스에서 빌드해야됨)

colcon build --packages-select ros_dd_cpp

5. 환경 설정 적용
source install/setup.bash

6. 패키지 확인
ros2 pkg list | grep ros_dd_cpp

[git init]
1. ros2_ws 이동 

cd ~/ros2_ws

2. git 저장소 만들기

git init

3. git ignore 만들기

nano .gitignore

파일 내용:
build/
install/
log/

4. 현재 파일 확인

git status

5. 파일 추가 

git add .

6. 커밋

git commit -m "ROS2 project initial commit"

7. github 레포 생성

8. github 레포랑 연결

git remote add origin <GitHub_Repository_URL>

9. 브랜치 이름 설정 

git branch -M main

10. Push

git push -u origin main
