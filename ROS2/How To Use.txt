1. 워크스페이스의 src 폴더로 이동

cd ~/[워크스페이스 이름]/src 

2. ament_cmake 빌드 타입을 사용하여 C++ 패키지 생성
ros2 pkg create --build-type ament_cmake [원하는 패키지 이름]

3. 워크스페이스 루트로 이동

cd ~/ros2_ws

4. 특정 패키지만 빌드(무조건 워크스페이스에서 빌드해야됨)

colcon build --packages-select ros_dd_cpp

5. 환경 설정 적용
source install/setup.bash

6. 패키지 확인
ros2 pkg list | grep ros_dd_cpp
