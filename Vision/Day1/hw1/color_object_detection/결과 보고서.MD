**<전체 로직 순서>**

**1) 이미지 입력**

- 이미지 입력 -> OpenCV에서 기본적으로 BGR 형식으로 이미지를 읽음 

**2) BGR -> HSV 변환**

- OpenCV에서는 기본적으로 BGR 형식으로 읽힘 
-> 이번 과제의 목적은 색상 검출이므로 BGR값을 바로 사용하지않고 HSV 색 공간으로 변환하여 사용했음. 

**3) 색상별 Mask 생성**

- HSV 이미지에서 inRange() 이용 -> Red, Blue, Green 각각의 색상 범위 지정

- inRange()는 지정한 HSV 범위에 들어가는 픽셀을 255, 범위에 벗어나는 픽셀은 0으로 만들어 Binary Mask를 생성

- 따라서 각 색상에 해당하는 객체 영역만 흰색으로 분리 가능 

**4) Red Mask는 따로 결합 시켜줌**

- Hue 범위에서 하나의 연속된 범위로 표현 안됨 -> H의 양 끝 영역이 나눠져 있음 -> 두개로 나눠서 검출한 뒤 OR연산으로 합쳐줌

**5) Red Mask에 Morphology Closing 적용**

- 색상 분할 과정에서 생성된 Mask에 작은 검은색 영역이나 끊어진 부분이 생길 수 있음
-> 이를 그대로 사용하면 빨간 공이 여러개로 검출될 수 있음(실제로 겪었던 이슈)

- 침식을 사용하지 않은 이유: 객체 실제 크기 최대한 유지하면서 박스를 그려야되는데 침식을 사용하면 객체의 크기를 불필요하게 줄일 수 있기 때문

- 팽창을 사용하지 않은 이유: 침식과 같은 이유이지만 반대 상황, 실제 크기보다 객체가 크게 잡힐 가능성이 있기 때문

- 열기를 사용하지 않은 이유: Red Mask에서 문제 발생함 -> 열기는 흰색 노이즈를 제거하는 목적인데 Red Mask는 끊어진 부분이나 검은색 영역을 연결해야함 -> Opening보단 Closing이 조금 더 목적에 맞는 선택이라고 생각함. 

**6) Contour 검출 -> 500.0 보다 큰 countour 모두 선택**

- Mask에서 findCountours() 이용 -> 색상 영역의 외곽선을 검출 

- 윤곽이 검축되면 countourArea() 이용 -> 윤곽 면적 게산

- 면적이 500보다 작으면 객체가 아닌 노이즈일 가능성이 있다고 판단하여 제외

**7) Bounding Box 계산 -> 색상별 Bounding Box 그리기**

- 면적 조건을 통과한 윤곽에 대해 boundingRect() 사용 -> 객체를 감싸는 사각형 위치와 크기 게산

**8) 결과 이미지 저장** 

- imwrite() 사용 -> 결과 이미지를 result.png라는 이름으로 저장

<br>
**<왜 순서를 이렇게 짰는가?>**

원본 이미지에서 바로 객체의 위치를 찾는 것이 아니라, 먼저 색상을 기준으로 관심 영역을 분리하고, 빨간색 Mask의 경우 영역을 나눠서 영역을 정리한 후, 각 색상의 Mask에서 Contour를 검출하여 객체의 위치를 계산하는 방식으로 구성하였다.
