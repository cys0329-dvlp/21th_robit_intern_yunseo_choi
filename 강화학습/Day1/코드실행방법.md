# MNIST MLP 코드 실행 방법


## 1. 필요한 라이브러리

- PyTorch
- TrochVision
- Numpy
- Matplotlib
- tqdm

### Windows

```powershell
py -m pip install --upgrade pip
py -m pip install torch torchvision numpy matplotlib tqdm
```

### macOS 또는 Linux

```bash
python3 -m pip install --upgrade pip
python3 -m pip install torch torchvision numpy matplotlib tqdm
```

## 2. 코드 파일 준비

`deeplearning.py`와 이 안내 파일을 컴퓨터에 내려받거나 복사합니다. 

## 3. 터미널에서 코드 폴더로 이동 

### windows & Linux 

```cd "<코드 폴더 경로>```

예를 들어 ```C:\Users\사용자이름\Desktop```에 있다면 ```cd "C:\Users\사용자이름\Desktop```입력

## 3. 코드 실행

현재 터미널 위치가 `deeplearning.py`가 있는 폴더인지 확인한 뒤 실행합니다.

### Windows

```powershell
py deeplearning.py
```

### macOS 또는 Linux

```bash
python3 deeplearning.py
```

`py`, `python3` 명령이 없는 환경에서는 설치된 Python 실행 명령에 맞게 바꿉니다. 가상 환경을 활성화했다면 `python deeplearning.py`로 실행해도 됩니다.

## 4. 실행 결과

학습 중에는 각 epoch의 다음 결과가 터미널에 표시됩니다.

- 학습 Loss와 Accuracy
- 검증 Loss와 Accuracy
- 현재 Learning Rate

학습이 끝나면 테스트 데이터의 `Final Test Loss`와 `Final Test Accuracy`가 출력됩니다. 이후 학습·검증 그래프와 오분류 이미지가 표시됩니다.

오분류 결과 보는 법

결과 그래프 오른쪽 위의 x 표시를 누르면 오분류 결과창이 나옵니다.
또한 로그로 몇개의 오분류가 존재하는지 텍스트로 출력됩니다.
