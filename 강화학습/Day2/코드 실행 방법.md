# Day2 FrozenLake Q-learning 실행 방법

이 문서는 `main.py`를 처음 받는 사람이 Python 환경을 준비하고, FrozenLake Q-learning 학습과 평가를 실행하는 방법을 설명합니다.

## 1. 준비 사항

- Python 3.10 이상 권장
- 인터넷 연결(처음 패키지를 설치할 때 필요)
- 터미널 또는 명령 프롬프트

사용 라이브러리:

- Gymnasium
- NumPy
- Matplotlib

## 2. 프로젝트 폴더로 이동

저장소를 내려받거나 복제한 뒤, 터미널에서 `main.py`가 있는 `Day2` 폴더로 이동합니다.

```bash
cd "강화학습/Day2"
```

실행 전에 현재 위치에 `main.py`가 있는지 확인합니다.

```bash
ls
```

Windows 명령 프롬프트에서는 `ls` 대신 `dir`을 사용할 수 있습니다.

## 3. 가상 환경 만들기 (권장)

가상 환경은 이 프로젝트의 Python 패키지를 다른 프로젝트와 분리합니다.

### Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### Windows PowerShell

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

PowerShell 실행 정책 때문에 활성화가 막히면, 활성화 명령 대신 `.venv` 안의 Python 실행 파일을 직접 사용할 수 있습니다.

## 4. 필요한 패키지 설치

가상 환경을 활성화한 상태에서 다음 명령을 실행합니다.

```bash
python -m pip install --upgrade pip
python -m pip install gymnasium numpy matplotlib
```

Linux/macOS에서 `python` 명령이 없다면 `python3 -m pip ...` 형식으로 실행합니다. Windows에서는 `py -m pip ...`를 사용할 수 있습니다.

## 5. 실행

현재 작업 위치가 `Day2` 폴더인지 확인한 뒤 실행합니다.

```bash
python main.py or python slip.py
```

환경에 따라 다음 명령을 사용해야 할 수 있습니다.

```bash
python3 main.py or python3 slip.py
```

또는 Windows:

```powershell
py main.py or py slip.py 
```

## 6. 실행 과정과 출력

현재 코드의 실행 순서는 다음과 같습니다.

1. `is_slippery=True`인 FrozenLake 환경에서 20,000 에피소드 학습합니다.
2. 1,000 에피소드 단위로 진행 번호와 누적 보상 기반 숫자를 출력합니다.
3. 학습이 끝나면 Q-table을 `q_table.npy`에 저장합니다.
4. Q-value heatmap과 학습 보상·성공률 곡선을 PNG로 저장합니다.
5. 그래프 창을 표시합니다. 창을 닫으면 이후 평가 코드가 계속 실행됩니다.
6. 저장한 Q-table을 불러와 ε=0인 greedy 정책으로 200회 평가합니다.
7. 성공 횟수와 성공률을 터미널에 출력합니다.
8. 정책 격자를 터미널에 출력합니다.

학습 도중 출력되는 진행 숫자는 평가 성공률이 아닙니다. 평가 성공률은 학습과 그래프 창 처리 이후 마지막에 `성공 횟수`, `성공률`로 출력됩니다.

## 7. 생성되는 파일

코드는 **명령을 실행한 현재 작업 폴더**에 다음 파일을 생성합니다.

| 파일 | 내용 |
|---|---|
| `q_table.npy` | 학습된 Q-table NumPy 바이너리 파일 |
| `q_table_heatmap.png` | 행동별 Q값을 보여주는 heatmap |
| `training_curves.png` | 100-episode 이동 평균 보상 및 성공률 그래프 |

다시 실행하면 같은 이름의 파일을 새 학습 결과로 덮어씁니다. 결과를 보관하려면 실행이 끝난 뒤 파일을 다른 이름이나 폴더로 복사해 두세요.

## 8. Q-table 파일 확인

`q_table.npy`는 텍스트 파일이 아니므로 편집기에서 직접 읽기 어렵습니다. 프로젝트 폴더에서 Python을 실행한 뒤 다음을 입력해 값을 확인할 수 있습니다.

```python
import numpy as np

q_table = np.load("q_table.npy")
print("shape:", q_table.shape)
print(q_table)
```

일반적으로 shape은 `(4, 4, 4)`입니다. 축의 순서는 행동, 행, 열입니다.

## 9. 자주 발생하는 문제

### `python` 또는 `python3` 명령을 찾을 수 없음

Python 3을 설치한 다음 터미널을 다시 열어 보세요. Windows에서는 `py main.py`, Linux/macOS에서는 `python3 main.py`를 시도할 수 있습니다.

### `ModuleNotFoundError`

필요한 패키지를 현재 실행에 사용한 Python 환경에 설치했는지 확인합니다.

```bash
python -m pip install gymnasium numpy matplotlib
```

가상 환경을 사용하는 경우 실행 전에 해당 환경을 활성화해야 합니다.

### `q_table.npy`를 찾을 수 없음

`main.py`가 있는 폴더에서 실행했는지 확인하세요. 상대 경로로 저장하므로 파일 위치는 명령을 실행한 현재 작업 폴더 기준입니다. 이 스크립트는 한 번 실행할 때 학습 후 저장하고 곧바로 같은 파일을 불러옵니다.

### 결과 그래프 창에서 프로그램이 멈춘 것처럼 보임

`plt.show()`가 그래프 창을 닫을 때까지 기다리는 동작일 수 있습니다. 그래프 창을 닫으면 평가가 이어집니다.

## 10. 실행 동작 관련 참고

- 학습 환경과 평가 환경 모두 `is_slippery=True`이므로 전이가 확률적입니다. 실행할 때마다 학습·평가 결과가 달라질 수 있습니다.
- 평가 정책은 ε=0이지만, 환경의 미끄러짐은 남아 있어 같은 정책에서도 이동 경로가 달라질 수 있습니다.
- 평가 환경은 `render_mode="human"`으로 생성되어 있지만, 현재 `main.py`에는 `env2.render()` 호출이 없습니다. 따라서 이 설정만으로 평가 에피소드의 움직임 화면이 표시된다고 보장되지 않습니다. 평가 결과는 터미널의 성공 횟수와 성공률을 확인하세요.
- 재현성을 위해 난수 시드를 고정하는 설정은 현재 코드에 없습니다. 실험 결과를 비교할 때는 사용한 코드 설정과 실행 결과를 함께 기록하세요.
